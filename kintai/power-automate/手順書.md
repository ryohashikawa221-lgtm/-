# 勤怠記録（PC ＋ Microsoft Forms ＋ Power Automate）設定手順書

職員が会社のPCに指紋でログインすると、打刻フォームが自動で開きます。職員は **「送信」を押すだけ** です。
記録はあなたの Excel と Outlook カレンダーにだけ残り、**職員は見ることも書き換えることもできません。**

```
職員：PCに指紋でログイン
   │  （スタートアップのショートカットで、フォームが自動で開く。「出勤」は選択済み）
   ▼
「送信」を押す
   │
   ▼
フロー（あなたのアカウントで動く。職員は中身を見られない）
   ├─ 時刻を記録（Microsoft のサーバーの時刻。PCの時計は使わない）
   ├─ あなたの Excel「勤怠記録.xlsx」に1行追加
   ├─ あなたの Outlook カレンダー「勤怠」に予定を作成
   │     例：「【遅刻12分】山田 太郎 出勤 09:12」
   └─ 遅刻のときだけ、あなたにメール
```

| ごまかし | 防ぎ方 |
|---|---|
| 記録を書き換える・消す | Excel・カレンダー・フォームの回答は、すべてあなた専用。職員には共有しない |
| 送った後で回答を直す | フォームの設定で、送信後の編集をできないようにする |
| PCの時計をずらす | 時刻は Microsoft のサーバーで付ける |
| 代わりに送る | 本人の Microsoft アカウントでないと送れず、送った人の名前が自動で記録される |
| フローを改造する | フローはあなたのアカウントにあり、職員には見えない |

**できないこと**：フォームは会社の外（スマホや自宅のPC）からも送れてしまいます。
6人の職場なら「自宅で送ってから遅れて出社」は周りが気づくので、実用上は問題ないはずです。

所要時間：あなたの作業が 40 分ほど、職員のPC1台あたり 3 分。
必要なもの：Office 365 A3（追加料金なし。使うのはすべて標準機能です）

---

## 手順1. Excel とカレンダーを用意する（5分）

1. あなたの OneDrive に **「勤怠」** フォルダを作り、同梱の **`勤怠記録.xlsx`** をアップロードします。
   **このフォルダもファイルも誰にも共有しません。**
2. Outlook（Web版）のカレンダーで「予定表を追加」→「空白の予定表を作成」→ 名前を **「勤怠」** にします。これも共有しません。
3. `勤怠記録.xlsx` の「月次集計」シートの黄色いセル（A6〜）に、職員のメールアドレス（`○○@○○.onmicrosoft.com`）を入力しておきます。

## 手順2. 打刻フォームを作る（10分）

1. [forms.office.com](https://forms.office.com) にあなたのアカウントでサインインし、「新しいフォーム」を作ります。
2. タイトル：**`打刻`**
3. 「新規追加」→ **「選択肢」** で質問を1つだけ作ります。
   - 質問：**`種類`**
   - 選択肢：**`出勤`** と **`退勤`**
   - **「必須」をオン**
4. 右上の「…」→ **「設定」** で次のようにします。
   - **「組織内のユーザーのみが回答可能」** を選び、**「名前を記録」をオン**
   - 「1人につき1つの回答」：**オフ**（毎日何回も送るため）
   - 「回答の受信後に編集を許可」などの、**送信後に回答を直せる設定があればオフ**
5. **「結果の概要を共有」はしない**でください（職員に他の人の回答が見えてしまいます）。

### 出勤用・退勤用のリンクを作る

1. 右上の「…」→ **「事前入力された URL を取得」** を選びます。
2. 「種類」で **出勤** を選んだ状態で「事前入力された URL を取得」→ URL をコピーし、メモ帳に **「出勤用」** として貼っておきます。
3. 同じようにして、**退勤** を選んだ URL を **「退勤用」** として控えます。

## 手順3. フローを作る（20分）

[make.powerautomate.com](https://make.powerautomate.com) にあなたのアカウントでサインインします。

1. 左の「作成」→ **「自動化したクラウド フロー」** を選びます。
2. フロー名：**`打刻の記録`**、トリガー：Microsoft Forms の **「新しい応答が送信されるとき」**（When a new response is submitted）→「作成」。
3. トリガーの「フォーム ID」で **打刻** を選びます。

ここからアクションを順番に追加します。
「＋」→ アクションを検索して追加 →「…」→「名前の変更」で**名前を表のとおりに変えてください**（式が名前で互いを参照するため、名前が違うと動きません）。

### 3-1. 回答の中身を取り出す

1. **Microsoft Forms** の **「応答の詳細を取得する」**（Get response details）を追加し、名前を **`応答`** にします。
   - フォーム ID：**打刻**
   - 応答 ID：動的なコンテンツから、トリガーの **「応答 ID」**

### 3-2. 「作成」アクションを並べる

「データ操作」の **「作成」**（Compose）を追加し、「入力」に式を入れます。
「式」は、入力欄をクリック →「fx」（または「式」タブ）に貼り付けて「追加」。
「動的なコンテンツ」とある所は、式ではなく一覧から選びます。

| 順番 | 名前 | 入力 |
|---|---|---|
| 1 | `現在時刻` | 式：`convertFromUtc(utcNow(),'Tokyo Standard Time','yyyy-MM-ddTHH:mm:ss')` |
| 2 | `メール` | 動的なコンテンツ：「応答」の **「回答者のメール」**（Responders' Email） |
| 3 | `種類` | 動的なコンテンツ：「応答」の **「種類」**（質問の答え） |

続けて、**Office 365 Users** の **「ユーザー プロフィールの取得 (V2)」**（Get user profile (V2)）を追加し、名前を **`プロフィール`** にします。
- ユーザー (UPN)：動的なコンテンツ `メール` の出力

さらに「作成」を3つ追加します。

| 順番 | 名前 | 入力 |
|---|---|---|
| 4 | `名前` | 式：`body('プロフィール')?['displayName']` |
| 5 | `遅刻分` | 式：下の「遅刻分の式」 |
| 6 | `Key` | 式：`concat(formatDateTime(outputs('現在時刻'),'yyyy/MM/dd'),'_',outputs('メール'),'_',outputs('種類'))` |

**遅刻分の式**（9:00 始業の場合）

```
if(and(equals(outputs('種類'),'出勤'),greater(add(mul(int(formatDateTime(outputs('現在時刻'),'HH')),60),int(formatDateTime(outputs('現在時刻'),'mm'))),540)),sub(add(mul(int(formatDateTime(outputs('現在時刻'),'HH')),60),int(formatDateTime(outputs('現在時刻'),'mm'))),540),0)
```

> **始業時刻を変えるとき**：`540` は 9:00（9×60分）です。8:30 なら `510` に、2か所とも変えます。
> **猶予を付けるとき**：1つ目の `540` だけを `545` にすると、9:05 までは遅刻0分、9:06 なら遅刻6分になります。
> フローは送信から数秒〜1分ほど遅れて動くことがあります。気になる場合は猶予を1〜2分付けてください。

### 3-3. その日すでに送っていないか調べる

1. **Excel Online (Business)** の **「表内に存在する行を一覧表示」**（List rows present in a table）を追加し、名前を **`今日の打刻`** にします。
2. 設定：
   - 場所：**OneDrive for Business**
   - ドキュメント ライブラリ：**OneDrive**
   - ファイル：`/勤怠/勤怠記録.xlsx`
   - テーブル：**打刻**
   - 詳細パラメーターの **「フィルター クエリ」**：`Key eq '` と入力 → 動的なコンテンツから **Key**（作成の出力）を選ぶ → 続けて `'` を入力
     （出来上がりは `Key eq '［Key］'` の形）

### 3-4. Excel に1行追加する

**Excel Online (Business)** の **「表に行を追加」**（Add a row into a table）を追加します。場所・ファイル・テーブルは 3-3 と同じです。

| 列 | 入力 |
|---|---|
| Key | 動的：`Key` の出力 |
| 日付 | 式：`formatDateTime(outputs('現在時刻'),'yyyy/MM/dd')` |
| 時刻 | 式：`formatDateTime(outputs('現在時刻'),'HH:mm')` |
| 年月 | 式：`formatDateTime(outputs('現在時刻'),'yyyyMM')` |
| 名前 | 動的：`名前` の出力 |
| メール | 動的：`メール` の出力 |
| 種類 | 動的：`種類` の出力 |
| 初回 | 式：`if(empty(body('今日の打刻')?['value']),'○','')` |
| 遅刻分 | 動的：`遅刻分` の出力 |
| 記録日時 | 動的：`現在時刻` の出力 |
| 備考 | 空欄 |

### 3-5. その日最初の送信なら、カレンダーに入れて、遅刻ならメール

1. **「条件」**（Condition）を追加します。
   - 左：式 `empty(body('今日の打刻')?['value'])`
   - 真ん中：**次の値に等しい**（is equal to）／右：式 `true`
2. **「True の場合」** に **Office 365 Outlook** の **「イベントの作成 (V4)」**（Create event (V4)）を追加します。
   - 予定表 ID：**勤怠**
   - 件名：式（下の「件名の式」）
   - 開始時刻：動的 `現在時刻` の出力
   - 終了時刻：式 `addMinutes(outputs('現在時刻'),15,'yyyy-MM-ddTHH:mm:ss')`
   - タイム ゾーン：**(UTC+09:00) 大阪、札幌、東京**
3. 同じ「True の場合」の中、イベントの作成の下にもう一つ **「条件」** を追加します。
   - 左：式 `greater(outputs('遅刻分'),0)`／真ん中：**次の値に等しい**／右：式 `true`
   - その「True の場合」に **Office 365 Outlook** の **「メールの送信 (V2)」**
     - 宛先：あなたのメールアドレス
     - 件名：件名の式と同じ式
     - 本文：`勤怠記録.xlsx で詳細を確認できます。`

**件名の式**

```
concat(if(greater(outputs('遅刻分'),0),concat('【遅刻',string(outputs('遅刻分')),'分】'),''),outputs('名前'),' ',outputs('種類'),' ',formatDateTime(outputs('現在時刻'),'HH:mm'))
```

右上の「保存」を押します。

## 手順4. 自分でテストする（5分）

1. 控えておいた **出勤用の URL** をブラウザで開いて「送信」します。
2. 1分ほど待って、次を確認します。
   - `勤怠記録.xlsx` の「打刻」シートに1行増えている
   - **年月**と**遅刻分**の列が右寄せ（＝数値）になっている。左寄せ（文字）だと月次集計に数えられません
   - 「勤怠」カレンダーに予定ができている
3. もう一度送って、Excel に行は増えるが「初回」が空欄で、カレンダーには増えないことを確認します。
4. うまくいかないときは「マイ フロー」→「打刻の記録」→「28日間の実行履歴」で、赤くなったアクションを開くと原因がわかります。
5. テストの行は Excel で行ごと削除してかまいません。

## 手順5. 職員のPCに設定する（1台3分）

職員がPCにログインした状態で行います。

1. **ログイン時に出勤フォームを自動で開く**
   - キーボードで **Windows キー＋R** →「`shell:startup`」と入力して Enter
   - 開いたフォルダの何もない所で右クリック →「新規作成」→「ショートカット」
   - 項目の場所に **出勤用の URL** を貼り付け →「次へ」→ 名前を **`出勤`** →「完了」
2. **デスクトップに退勤ボタンを置く**
   - デスクトップで右クリック →「新規作成」→「ショートカット」
   - **退勤用の URL** を貼り付け → 名前を **`退勤`** →「完了」
3. 一度サインアウトしてログインし直し、フォームが自動で開くこと、職員のアカウントで送信できることを確認します。
   （初回だけ Microsoft アカウントのサインインを求められることがあります）

## 毎日・毎月の使い方

- **今日の出勤状況**：Outlook の「勤怠」カレンダーを開く。遅刻は件名の頭に【遅刻○分】が付きます。
- **月の集計**：`勤怠記録.xlsx` の「月次集計」で、黄色のセルに `202610` のように年月を入れる。出勤日数・遅刻回数・遅刻合計（分）が出ます。
- **送り忘れ・修正**：職員から申し出があったら、あなたが「打刻」シートを直し、「備考」に理由を書きます（送り忘れなら行を追加）。
- **元の記録**：Forms の「応答」タブにも、送信日時つきで全部残っています。Excel を直しても、こちらは変わりません。

## 職員への説明の例

> 来月から、出退勤はPCで記録します。
> PCにログインすると打刻フォームが開くので「送信」を押してください。帰るときはデスクトップの「退勤」から送信してください。
> 記録は管理者だけが確認します。送り忘れや電車遅延などで修正が必要なときは、その日のうちに申し出てください。

## 注意

- 遅刻を理由に給与を減らすときは、就業規則に書いておく必要があります。
- 組織の Microsoft 365 管理者が Forms や Power Automate を制限している場合は、管理者に許可してもらってください。
