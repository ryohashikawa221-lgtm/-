# 勤怠記録（Power Automate ＋ Outlook カレンダー）設定手順書

職員はスマホの Power Automate アプリで「出勤」「退勤」ボタンを押すだけ。
記録はあなたの OneDrive の Excel とあなたの Outlook カレンダーに残り、**職員は見ることも書き換えることもできません。**

```
職員：スマホの「出勤」ボタン
   │
   ▼
フロー（あなたのアカウントで動く。職員は中身を見られない）
   ├─ 時刻を記録（Microsoft のサーバーの時刻。スマホの時計は使わない）
   ├─ 位置情報から「社内／社外／不明」を判定
   ├─ あなたの Excel「勤怠記録.xlsx」に1行追加
   ├─ あなたの Outlook カレンダー「勤怠」に予定を作成
   │     例：「【遅刻12分】山田 出勤 09:12」
   └─ 遅刻・社外・不明のときだけ、あなたにメール
```

| ごまかし | 防ぎ方 |
|---|---|
| 記録を書き換える・消す | Excel とカレンダーはあなた専用。職員には共有しない |
| 時計をずらす | 時刻は Microsoft のサーバーで付ける |
| 自宅から押す | 位置情報で「社外」と記録され、あなたにメールが届く |
| PC から押して位置をごまかす | 位置情報が無い打刻は「不明」として記録され、メールが届く |
| 代わりに押す | 本人の Microsoft アカウントでログインしないと押せない |
| フローを改造する | 職員は「実行のみ」の権限なので、中身を見ることも変えることもできない |

所要時間：あなたの作業が 40〜60 分、職員1人あたり 5 分。
必要なもの：Office 365 A3（追加料金なし。Excel・Outlook の連携は標準機能の範囲です）

---

## 手順1. Excel とカレンダーを用意する（5分）

1. あなたの OneDrive に **「勤怠」** フォルダを作り、同梱の **`勤怠記録.xlsx`** をアップロードします。
   **このフォルダもファイルも誰にも共有しません。**
2. Outlook（Web版）のカレンダーで「予定表を追加」→「空白の予定表を作成」→ 名前を **「勤怠」** にします。これも共有しません。
3. `勤怠記録.xlsx` を開き、「月次集計」シートの黄色いセル（A6〜）に職員のメールアドレス（`○○@○○.onmicrosoft.com`）を入力しておきます。

## 手順2. 会社の位置を調べる（2分）

1. Google マップで会社の建物を右クリックします。
2. 一番上に出る `35.681236, 139.767125` のような数字をメモします。
   前が **緯度**、後ろが **経度** です。

> 以下の手順の式に出てくる `35.681236` と `139.767125` は例（東京駅）です。**必ず自分の会社の数字に置き換えてください。**
> 判定範囲は会社から約 300m 四方です。広げたいときは式の `300` と `-300` を変えます。

## 手順3. 「出勤」フローを作る（30分）

[make.powerautomate.com](https://make.powerautomate.com) にあなたのアカウントでサインインします。

1. 左の「作成」→ **「インスタント クラウド フロー」** を選びます。
2. フロー名を **`出勤`**、トリガーを **「フローを手動でトリガーする」**（Manually trigger a flow）にして「作成」を押します。

ここからアクションを順番に追加します。
「＋」→ アクションを検索して追加 →「…」→「名前の変更」で**名前を表のとおりに変えてください**（式が名前で互いを参照するため、名前が違うと動きません）。

### 3-1. 「作成」アクションを 10 個並べる

「データ操作」の **「作成」**（Compose）を追加し、「入力」に式を入れます。
「式」の入力は、入力欄をクリック →「fx」（または「式」タブ）に貼り付けて「追加」です。
「動的なコンテンツ」とある所は、式ではなく一覧から選びます。

| 順番 | 名前 | 入力 |
|---|---|---|
| 1 | `現在時刻` | 式：`convertFromUtc(utcNow(),'Tokyo Standard Time','yyyy-MM-ddTHH:mm:ss')` |
| 2 | `名前` | 動的なコンテンツ：トリガーの **「ユーザー名」**（User name） |
| 3 | `メール` | 動的なコンテンツ：トリガーの **「ユーザーのメール」**（User email） |
| 4 | `緯度元` | 動的なコンテンツ：トリガーの **「緯度」**（Latitude） |
| 5 | `経度元` | 動的なコンテンツ：トリガーの **「経度」**（Longitude） |
| 6 | `緯度` | 式：`float(if(empty(string(outputs('緯度元'))),'0',string(outputs('緯度元'))))` |
| 7 | `経度` | 式：`float(if(empty(string(outputs('経度元'))),'0',string(outputs('経度元'))))` |
| 8 | `場所` | 式：下の「場所の式」 |
| 9 | `遅刻分` | 式：`if(greater(add(mul(int(formatDateTime(outputs('現在時刻'),'HH')),60),int(formatDateTime(outputs('現在時刻'),'mm'))),540),sub(add(mul(int(formatDateTime(outputs('現在時刻'),'HH')),60),int(formatDateTime(outputs('現在時刻'),'mm'))),540),0)` |
| 10 | `Key` | 式：`concat(formatDateTime(outputs('現在時刻'),'yyyy/MM/dd'),'_',outputs('メール'),'_出勤')` |

**場所の式**（緯度・経度の数字を自分の会社のものに置き換える）

```
if(equals(outputs('緯度'),0),'不明',if(and(less(mul(sub(outputs('緯度'),35.681236),111000),300),greater(mul(sub(outputs('緯度'),35.681236),111000),-300),less(mul(sub(outputs('経度'),139.767125),91000),300),greater(mul(sub(outputs('経度'),139.767125),91000),-300)),'社内','社外'))
```

> **始業時刻を変えるとき**：遅刻分の式の `540` は 9:00（9×60分）です。8:30 なら `510` に、2か所とも変えてください。
> 5分の猶予を付けたいときは、最初の `540` だけを `545` にします（9:05 までは遅刻0分、9:06 なら遅刻6分）。

### 3-2. その日すでに出勤を押したか調べる

1. **Excel Online (Business)** の **「表内に存在する行を一覧表示」**（List rows present in a table）を追加し、名前を **`今日の打刻`** にします。
2. 設定：
   - 場所：**OneDrive for Business**
   - ドキュメント ライブラリ：**OneDrive**
   - ファイル：`/勤怠/勤怠記録.xlsx`
   - テーブル：**打刻**
   - 詳細パラメーターの **「フィルター クエリ」**：`Key eq '` と入力 → 動的なコンテンツから **Key**（作成アクションの出力）を選ぶ → 続けて `'` を入力
     （出来上がりは `Key eq '［Key］'` の形）

### 3-3. Excel に1行追加する

1. **Excel Online (Business)** の **「表に行を追加」**（Add a row into a table）を追加します。場所・ファイル・テーブルは 3-2 と同じにします。
2. 列ごとに次を入れます。

| 列 | 入力 |
|---|---|
| Key | 動的：`Key` の出力 |
| 日付 | 式：`formatDateTime(outputs('現在時刻'),'yyyy/MM/dd')` |
| 時刻 | 式：`formatDateTime(outputs('現在時刻'),'HH:mm')` |
| 年月 | 式：`formatDateTime(outputs('現在時刻'),'yyyyMM')` |
| 名前 | 動的：`名前` の出力 |
| メール | 動的：`メール` の出力 |
| 種類 | 文字：`出勤` |
| 初回 | 式：`if(empty(body('今日の打刻')?['value']),'○','')` |
| 遅刻分 | 動的：`遅刻分` の出力 |
| 場所 | 動的：`場所` の出力 |
| 緯度 | 動的：`緯度元` の出力 |
| 経度 | 動的：`経度元` の出力 |
| 住所 | 動的：トリガーの **「完全な住所」**（Full address） |
| 記録日時 | 動的：`現在時刻` の出力 |
| 備考 | 空欄 |

### 3-4. その日最初の出勤なら、カレンダーに入れて必要ならメール

1. **「条件」**（Condition）を追加します。
   - 左：式 `empty(body('今日の打刻')?['value'])`
   - 真ん中：**次の値に等しい**（is equal to）
   - 右：式 `true`
2. **「True の場合」** の中に、**Office 365 Outlook** の **「イベントの作成 (V4)」**（Create event (V4)）を追加します。
   - 予定表 ID：**勤怠**
   - 件名：式（下の「件名の式」）
   - 開始時刻：動的 `現在時刻` の出力
   - 終了時刻：式 `addMinutes(outputs('現在時刻'),15,'yyyy-MM-ddTHH:mm:ss')`
   - タイム ゾーン：**(UTC+09:00) 大阪、札幌、東京**
   - 本文（詳細パラメーター、任意）：動的 **「完全な住所」**
3. 同じ「True の場合」の中、イベントの作成の下に、もう一つ **「条件」** を追加します。
   - 左：式 `or(greater(outputs('遅刻分'),0),not(equals(outputs('場所'),'社内')))`
   - 真ん中：**次の値に等しい**／右：式 `true`
   - その「True の場合」に **Office 365 Outlook** の **「メールの送信 (V2)」** を追加します。
     - 宛先：あなたのメールアドレス
     - 件名：件名の式と同じ式
     - 本文：動的 **「完全な住所」**

**件名の式**

```
concat(if(greater(outputs('遅刻分'),0),concat('【遅刻',string(outputs('遅刻分')),'分】'),''),if(equals(outputs('場所'),'社内'),'',concat('【',outputs('場所'),'】')),outputs('名前'),' 出勤 ',formatDateTime(outputs('現在時刻'),'HH:mm'))
```

右上の「保存」を押します。

## 手順4. 「退勤」フローを作る（10分）

1. 「マイ フロー」で「出勤」の「…」→ **「名前を付けて保存」** → 名前を **`退勤`** にします。
2. 「退勤」を編集し、次の4か所だけ変えます。
   - `Key` の式の末尾 `'_出勤'` → `'_退勤'`
   - 「表に行を追加」の 種類 → `退勤`
   - 「表に行を追加」の 遅刻分 → 文字で `0`
   - 件名の式（イベントとメールの2か所）の `' 出勤 '` → `' 退勤 '`、`greater(outputs('遅刻分'),0)` → `false`
3. 2つ目の条件（メール送信の条件）の左の式を `not(equals(outputs('場所'),'社内'))` に変えます。
4. 保存します。

## 手順5. 自分でテストする（5分）

1. スマホに **Power Automate** アプリを入れ、あなたのアカウントでサインインします（位置情報は「許可」）。
2. 「ボタン」タブの **「出勤」** を押します。
3. 次を確認します。
   - `勤怠記録.xlsx` の「打刻」シートに1行増えている
   - **年月**と**遅刻分**の列が右寄せ（＝数値）になっている。左寄せ（文字）だと月次集計に数えられません
   - 「勤怠」カレンダーに予定ができている
   - 会社以外の場所で押したなら「社外」になってメールが届く
4. うまくいかないときは、make.powerautomate.com の「マイ フロー」→ フロー →「28日間の実行履歴」で、赤くなったアクションを開くと原因がわかります。
5. テストの行は、Excel で行ごと削除してかまいません。

## 手順6. 職員が押せるようにする（職員1人5分）

1. make.powerautomate.com で「出勤」フローを開き、右下の **「実行のみのユーザー」** の「編集」を押します。
2. 職員6人（またはまとめたグループ）を追加します。
3. 下の接続（Excel Online (Business) と Office 365 Outlook）を、それぞれ **「（あなたの名前）の接続を使用」** に変えて保存します。
   → 職員が押しても、書き込みはあなたの権限で行われます。職員自身には Excel もカレンダーも共有されません。
4. 「退勤」フローにも同じことをします。
5. 各職員のスマホで：
   - Power Automate アプリを入れて、職員のアカウント（`@○○.onmicrosoft.com`）でサインイン
   - 位置情報を **「常に許可」または「使用中のみ許可」** にする
   - 「ボタン」タブに「出勤」「退勤」が出ていることを確認
   - ホーム画面にウィジェットを置くと、1タップで押せます

## 毎日・毎月の使い方

- **今日の出勤状況**：Outlook の「勤怠」カレンダーを開く。遅刻・社外の打刻は件名の頭に【】が付きます。
- **月の集計**：`勤怠記録.xlsx` の「月次集計」で、黄色のセルに `202610` のように年月を入れる。
  出勤日数・遅刻回数・遅刻合計（分）・社外/不明の打刻数が出ます。
- **修正**：職員から「電車遅延だった」などの申し出があったら、あなたが「打刻」シートの遅刻分を直し、「備考」に理由を書きます。

## 職員への説明の例

> 来月から、出退勤はスマホの Power Automate アプリの「出勤」「退勤」ボタンで記録します。
> 押した時刻と場所（会社にいるかどうか）が記録されます。記録は管理者だけが確認し、それ以外の目的には使いません。
> 押し忘れや遅延などで修正が必要なときは、その日のうちに申し出てください。

## 注意

- **押し忘れ**は記録が残らないだけなので、あなたの方で Excel に行を追加して対応します。
- 位置情報は、偽装アプリを使えばごまかすことも不可能ではありません。社外打刻が続く人がいれば、個別に確認してください。
- 位置情報の取得は、職員に事前に説明しておいてください。勤怠以外の目的には使わないことも伝えましょう。
- 遅刻を理由に給与を減らすときは、就業規則に書いておく必要があります。
- 組織の Microsoft 365 管理者が Power Automate を制限している場合は、管理者に許可してもらってください。
