# 勤怠記録（PCログイン連動タイムカード）

会社のPCに指紋（Windows Hello / Touch ID）でログインした時刻を自動で記録し、管理画面で出勤・退勤・遅刻を確認できる仕組みです。
職員が打刻ボタンを押す必要はありません。

## しくみ

```
職員のPC（Windows ×5）          あなたのMac
  ログイン・ロック解除・ロック      ログイン・ロック解除・ロック
  ＋15分ごとの「使用中」記録        ＋15分ごとの「使用中」記録
        │                               │
        ▼                               ▼
   OneDrive の共有フォルダ「勤怠記録」（職員ごとに 名前.csv）
        │
        ▼
   管理画面（dashboard/index.html をブラウザで開く）
```

- **出勤時刻** ＝ その日に最初にPCを使い始めた時刻（ログイン・ロック解除・使用中のうち最も早いもの）
- **退勤時刻** ＝ その日に最後にPCを使っていた時刻（最後のロック、または最後の「使用中」記録）
- 記録は OneDrive に保存されるので、PCがオフラインでも、つながった時点で同期されます。
- 記録するのは時刻・名前・PC名・種類だけです。画面の内容や操作内容は記録しません。

| フォルダ | 中身 |
|---|---|
| `windows/` | 職員のWindows PC用（`install.ps1` でセットアップ） |
| `mac/` | Mac用（`install.sh` でセットアップ） |
| `dashboard/` | 管理画面（`index.html`） |

---

## 1. 共有フォルダを用意する（最初に1回、あなたが行う）

1. あなたの OneDrive に **「勤怠記録」** という名前のフォルダを作ります。
2. そのフォルダを職員5人それぞれのMicrosoftアカウントに **「編集可能」** で共有します。
3. 各職員のPCで、共有されたフォルダを開き **「マイファイルにショートカットを追加」**（または「マイ OneDrive に追加」）を選びます。
   これで職員のPCのエクスプローラーにも「勤怠記録」フォルダが表示されます。

> 職員のPCで OneDrive にサインインしていることが前提です。

## 2. 職員のWindows PCをセットアップする（1台5分ほど）

その職員がPCにログインした状態で行います。

1. `windows` フォルダを、USBメモリなどで職員のPCにコピーします。
2. `install.ps1` を右クリックし、**「PowerShell で実行」** を選びます。
3. 名前を聞かれるので、管理画面に表示したい名前（例：`山田`）を入力します。
4. 緑色で「セットアップ完了」と表示されれば終わりです。共有フォルダに `山田.csv` ができています。

PCには次のものが入ります。

- `%LOCALAPPDATA%\Kintai\`：記録用プログラムと設定
- タスクスケジューラの `\Kintai\` フォルダ：ログオン・ロック解除・ロック・定期記録の4つのタスク

## 3. あなたのMacをセットアップする（任意）

あなた自身の出退勤も記録する場合だけ行います。管理画面を見るだけなら不要です。

```bash
xcode-select --install        # まだ入れていなければ（swiftc が必要）
cd kintai/mac
bash install.sh 自分の名前
```

途中で「OneDrive のファイルへのアクセス」の許可を求められたら「許可」してください。

## 4. 管理画面を使う

1. `dashboard/index.html` をブラウザ（Chrome または Edge がおすすめ）で開きます。
2. **「フォルダを開く」** で、OneDrive の「勤怠記録」フォルダを選びます。

| 画面 | できること |
|---|---|
| 日別 | その日の全員の出勤・退勤・遅刻 |
| 月次集計 | 職員ごとの遅刻回数・遅刻合計時間・平均出勤時刻・記録なしの日数、CSV書き出し |
| 個人別 | 1人分の1か月の記録。日ごとに時刻の修正や「休み」の登録ができます |
| 設定 | 始業時刻、遅刻にしない猶予（分）、勤務日、個人ごとの始業時刻 |

- **修正**は、共有フォルダの `修正.csv` に保存されます（元の記録は書き換えません）。
  Safari など直接保存できないブラウザでは `修正.csv` がダウンロードされるので、共有フォルダに上書きで入れてください。
- 「サンプルデータで試す」で、実際のデータが無くても画面を確認できます。

---

## 運用上の注意

- **導入前に全員へ説明してください。** 「記録するのはPCのログイン・ログオフの時刻だけ」「画面や操作内容は見ない」「時刻がずれた日は申し出れば修正する」ことを伝えておくと安心です。
- **PCの記録＝実際の出勤時刻ではありません。** 出社してすぐPCを開かなかった日は遅刻に見えます。本人から申し出があれば、個人別画面で修正してください。
- 遅刻分の給与を差し引く場合や、懲戒（減給）の判断に使う場合は、就業規則での定めが必要です。社労士などに確認してから運用してください。
- 職員は自分の CSV を編集できてしまいます。OneDrive の「バージョン履歴」で過去の状態を確認できます。気になる場合はWindowsのイベントログ（セキュリティ）とも突き合わせられます。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「フォルダが見つかりません」と出る | 手順1の「ショートカットを追加」を確認。場所が分かっていれば `install.ps1 -Name 山田 -FolderPath "D:\OneDrive\勤怠記録"` のように指定 |
| 「自動実行の確認ができませんでした」と出る | Windows を最新に更新してから再実行。タスクスケジューラで `\Kintai\` のタスクの「前回の実行結果」を確認 |
| 記録が届かない | そのPCで OneDrive にサインインしているか確認。書き込めなかった記録は `%LOCALAPPDATA%\Kintai\pending.csv` に一時保存され、次回自動で送られます |
| やめたい | Windows は `uninstall.ps1`、Mac は `bash uninstall.sh` を実行（記録済みの CSV は残ります） |

## 記録ファイルの形式

`勤怠記録/名前.csv`（UTF-8 BOM付き、Excelでそのまま開けます）

```
日時,名前,PC,種類
2026-10-19T08:57:12+09:00,山田,PC-01,logon
2026-10-19T09:12:00+09:00,山田,PC-01,active
2026-10-19T18:40:31+09:00,山田,PC-01,lock
```

種類：`logon`（ログイン）／`unlock`（ロック解除）／`lock`（ロック）／`active`（15分ごとの使用中記録）／`install`（セットアップ時のテスト。集計には使いません）

`勤怠記録/修正.csv`

```
日付,名前,出勤,退勤,理由
2026-10-16,山田,08:55,18:10,電車遅延
2026-10-17,山田,,,有休
```

出勤・退勤を空欄にすると「休み」として扱います。
