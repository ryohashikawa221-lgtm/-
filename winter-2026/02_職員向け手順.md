# 冬期講習2026 申込・定員管理 職員向け手順

画面：職員ポータル → 季節講習 → **「申込・定員管理」**（直接開く場合：`/portal/seasonal/admissions`）

保護者は **保護者ポータル → 冬期講習**（`/guardian/seasonal`）から申し込みます。お子さんと学年は学校の登録内容から自動で入ります。

## 0. どこで何を変えるか

| 変えたいこと | 変える場所 |
| --- | --- |
| 講座名・日時・授業内容・持ち物・教材・担当・対象学年・集団/個別・換算数・確定 | 季節講習の**時間割**（従来どおり） |
| 講座ごとの定員、締切・受付再開、2コマ続きの料金倍率、標準外講座の料金確認 | **申込・定員管理** |
| 講習全体の公開・受付終了 | 季節講習の時間割（公開操作） |
| 申込状況の確認、講座別名簿のCSV | **申込・定員管理** |

講座の内容は時間割で1回だけ編集します。保護者の画面にはそのまま反映されます（二重入力はありません）。

## 1. 権限

- 「時間割の管理」（`timetable.manage`）を持つ職員が使えます。担当校舎の講習だけが表示されます。
- 画面でボタンが見えていても、サーバーとデータベースでも権限を確認しています。
- 定員・締切・料金の変更はすべてデータベースの操作履歴に残ります（日時・操作した人・内容）。

## 2. 画面の見方

- **上の数字の枠**：受付中／残りわずか（2席以内）／満席／締切／準備中・要確認 の講座数と、申込家庭数・延べ受講申込数。枠を押すと、その講座だけに絞り込みます（もう一度押すと解除）。
- **絞り込み**：期間（サンクスギビング・冬期 第1〜第3ターム）、集団・個別、講座名・先生の検索、「要確認の講座だけ」。
- **一覧**：講座名・日程・担当、申込人数と定員（棒グラフ：緑＝7割未満、黄＝7割以上、赤＝満席）、残席、状態。
- **状態の違い**
  - **満席**：申込人数が定員に達した（自動）。
  - **締切**：職員が手動で止めた。残席があっても新しい申込は受け付けません。
  - **準備中**：時間割で未確定、または料金の確認が済んでいない。保護者は申し込めません。
  - **要確認**：標準（90分×3日、または180分×3日で換算数1）と違う講座。料金の確認が必要です。

## 3. 受付を始める前に（必ず）

1. 時間割で、受け付ける講座を **確定** にします（集団/個別・換算数・根拠の入力が必要）。
2. 申込・定員管理で **「要確認の講座だけ」** を表示し、1講座ずつ「設定」を開きます。
   - 換算数（何講座分と数えるか）は時間割の値、料金倍率は「通常（1倍）」か「2コマ続き（1.6倍）」です。
   - 両方を確かめたら **「換算数と倍率を両方確認済み」** にチェックして保存します。保存するまで保護者は申し込めません。
   - あとで時間割の日時・換算数・集団/個別を変えると、確認は自動で取り消されます（もう一度確認が必要）。
   - **1回だけ・2回だけの講座**は、今の仕組みでは「1講座分（3回分）」の料金でしか受け付けられません。料金を決めるまでは確認済みにしないでください（準備中のままになります）。
3. **料金の確認は受付開始前に終えてください。** 受付中に料金倍率や確認を変えると、画面を開いている保護者には「講座・料金の情報が更新されました」と表示され、金額を確かめ直してもらうことになります（選んだ講座は消えません）。
4. 必要に応じて定員を変えます（初期値：集団12名、個別3名）。

## 4. 定員を変える

1. 講座の行の **「設定」** を押します。
2. 定員を入力して **「保存」**。
   - 現在の申込人数より少なくはできません（その場合は保存されずに理由が表示されます）。

## 5. 途中で締め切る・再開する

- 締切：行の **「締め切る」** → 確認の表示で **「締め切る」**。
- 再開：行の **「受付を再開」** → **「受付を再開する」**。
- 締め切っても、すでに申し込んでいる方の申込はそのまま残ります。その方が内容を保存し直しても、締め切った講座は残せます。いったん外した講座を、締切中にもう一度選ぶことはできません。
- 締切と保護者の申込が同時に起きても、締切の後に新しい申込が入ることはありません。

## 6. 申込の確認・名簿

- 行の **「申込者（n人）」** で、その講座の申込者（名前・学年）を確認できます。
- **「講座別名簿をCSVで保存」** で、講座名・期間・日程・担当・定員・申込人数・残席・状態・生徒名・学年・家庭IDの一覧を保存できます（Excelで開けます）。

## 7. 保護者の変更・取消

- 保護者は、受付後も同じ画面で講座を選び直して「申し込む」を押すと変更できます。外した講座は取消になり、残席は自動で戻ります。料金（講座数割引・きょうだい割引）も自動で計算し直されます。
- 請求書を発行した後に変更があった場合、その請求は「変更確認中」になります。内容を確認してから請求を出し直してください。

## よくある質問

- **残席はどう数えていますか？** 保存されている申込の実数から計算しています。
- **申込が集中したら？** 1件ずつ順番に確認して保存するため、定員を超えて受け付けることはありません（最後の1席に同時に申し込んでも、受け付けるのは1件だけです）。
- **保護者が「申し込む」を2回押したら？** 同じ内容は1件として扱い、同じ受付番号を返します。
- **受付番号は？** `W26-` で始まる番号です（例：W26-1A2B-3C4D）。保護者の画面と、保護者ポータルの同じ画面でいつでも確認できます。
- **受付メールは？** 送っていません。保護者には受付番号を控えるよう案内しています。
