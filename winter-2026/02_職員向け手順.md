# 冬期講習2026 申込・定員管理 職員向け手順

画面：職員ポータル → 冬期講習2026の時間割 → **「申込・定員管理」**
（直接開く場合：`/portal/seasonal/applications`）

## 0. 役割分担（どこで何を変えるか）

| 変えたいこと | 変える場所 |
| --- | --- |
| 講座名・日時・授業内容・持ち物・教材・担当・対象学年 | 時間割（季節講習2026）※従来どおり |
| 集団／個別、講座数割引の換算数（＋その根拠）、講座の「確定」 | 時間割（季節講習2026） |
| 定員、途中締切・受付再開、料金倍率の確認値、教科の表示 | **申込・定員管理** |
| 受付開始・受付終了・締切日時 | **申込・定員管理** |
| 申込の確認・取消・講座追加、CSV出力、操作履歴 | **申込・定員管理** |

講座の内容は時間割で1回だけ編集します。申込画面にはそのまま反映されます（二重入力はありません）。

## 1. 権限

| 権限 | できること |
| --- | --- |
| 季節講習の申込を閲覧 | 申込一覧・残席・受付状態・操作履歴を見る、CSV出力 |
| 季節講習の定員・締切を管理 | 上に加えて、定員・締切・再開・料金倍率・受付期間の変更、申込の取消・追加 |

- 校長は両方を持っています。他の職員には、校長が「職員と権限」画面で個別に付与します。
- 画面でボタンが見えていなくても、サーバーとデータベースの両方で権限を確認しています。

## 2. 受付を始める前に

1. 時間割で、申込を受け付ける講座を **「確定」** にします。確定には、集団／個別・換算数・根拠の入力が必要です。
   - 確定していない講座は、保護者の画面で **「準備中」** と表示され、申し込めません。
2. 申込・定員管理の「講座と定員」で **「要確認の講座だけ」** にチェックを入れ、表示された理由を確認します。
   - **時間・回数が標準（90分×3回）と異なる講座** は、料金倍率が自動で決まりません。「変更」から料金倍率を入力してください（例：1回だけの講座）。
   - 2コマ連続（3時間×3回）の集団講座は自動で1.6倍、個別（90分×3回）は自動で1.4倍です。
   - 2コマ連続の講座を「講座数割引で何講座と数えるか」は時間割の **換算数** で決めます（料金倍率とは別の値です）。
3. 必要に応じて定員を変更します（初期値：集団12名、個別3名）。
4. 「受付期間・受付状態」で **受付中** を選び、必要なら締切日時（ミシガン時間）を入れて保存します。

## 3. 定員を変更する

1. 「講座と定員」で対象講座の **「変更」** を押します。
2. 「初期値」のチェックを外し、定員を入力します（0〜200）。初期値に戻すときはチェックを入れます。
3. 必要なら変更理由を入れて **保存** します。
   - 現在の申込数より少なくすると確認が表示されます。保存すると満席扱いになりますが、**申込済みの方は取り消されません**。

## 4. 途中で締め切る・再開する

- 締切：行の **「締め切る」** → 理由（任意）→「締め切る」
- 再開：行の **「受付を再開」** → 「受付を再開する」
- 締切中は保護者の画面に **「締切」** と表示されます。残席が残っていても申し込めません。
  （**満席**は「定員に達した」、**締切**は「職員が止めた」で、別の状態です。表の「受付」と「保護者への表示」で区別できます。）
- 保護者が締切前に講座を選んでいた場合も、送信時にもう一度確認し、申し込めない理由を画面で案内します。

## 5. 受付期間全体を終える

「受付期間・受付状態」で **受付終了** を選んで保存します（または締切日時を設定）。すべての講座が「締切」と表示されます。

## 6. 申込を確認する

「申込一覧」で受付番号・保護者名・メール・お子さんの名前で検索できます。行を開くと、連絡先・お子さんごとの講座・料金内訳が見られます。

- 申込は **1家庭（メールアドレス）1件** です。同じメールアドレスからの2回目の申込は受け付けず、学院へ連絡するよう案内しています。

## 7. 取消・講座の追加（変更）

1. 申込を開き、**取消・変更の理由（必須）** を入力します。
2. 取消：取り消す講座にチェック → **「選択した講座を取消」**。すべて取り消す場合は **「申込全体を取消」**。
3. 追加：お子さんの「講座を追加…」で講座を選び **「追加する」**（定員を超える場合は追加できません。職員の追加は手動締切中でも可能です）。
4. 保存すると、**残席が戻り（増え）**、ご家庭の料金（講座数割引・きょうだい割引）が再計算されます。
   - 既にある講座の料金は、申込時の倍率・換算数のまま計算します。

## 8. 請求担当への受け渡し

「申込一覧をCSVで保存」で、1行＝お子さん×講座の一覧（お子さんごとの定価・講座数割引・きょうだい割引・支払額、ご家庭合計）を出力します。金額は申込時にサーバーで計算・保存した値です。
※ 現時点では請求書の自動作成とはつながっていません（後述「未完了」参照）。

## 9. 操作履歴

「操作履歴」タブに、申込受付・定員変更・締切・再開・取消・追加・受付期間の変更が、日時・操作した人・前後の値・理由とともに残ります（後から変更・削除はできません）。

## よくある質問

- **残席はどう数えていますか？** 取消されていない申込講座の実数です。仮の数字は使っていません。
- **同時に申し込みが集中したら？** 1件ずつ順番に確認して保存するため、定員を超えて受け付けることはありません。
- **保護者が「申し込む」を2回押したら？** 同じ内容は1件として扱います（受付番号も同じ）。
- **メールは届きますか？** 受付メールは現在送信していません。保護者には受付番号の画面を控えるよう案内しています。
